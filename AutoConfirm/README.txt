วิธี build
1. ติดตั้ง Android Studio แล้ว File > Open เลือกโฟลเดอร์ AutoConfirm นี้ (รอ Gradle sync)
2. เปิด Developer options + USB debugging บน tablet แล้วเสียบสาย (หรือ Build > Build APK แล้วส่งไฟล์ไปติดตั้ง)
3. กด Run

วิธีใช้
1. เปิดแอป Auto Confirm > กดปุ่ม 1 > เปิดบริการ Auto Confirm
2. เปิดแอปจ่ายเงินของคุณ แล้วสลับกลับมา กด "ใช้แอปล่าสุดที่เปิดอยู่"
3. ตรวจข้อความปุ่ม กดบันทึก
4. เปิดสวิตช์ "เปิดกดอัตโนมัติ" เฉพาะตอนใช้งาน
